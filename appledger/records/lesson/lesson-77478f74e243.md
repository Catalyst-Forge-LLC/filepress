  context: Imported from workflow tracking gotchas[].
  problem: A prerendered dynamic route with an entries() that returns [] (e.g.
    /page/[n] on a site small enough to fit on page 1) fails the adapter-static
    build with 'marked as prerenderable but not prerendered'.
  resolution: Set kit.prerender.handleUnseenRoutes in vite.config.ts to a function
    that ignores exactly '/page/[n]' and still throws for any other unseen
    route, so the build stays strict elsewhere.
