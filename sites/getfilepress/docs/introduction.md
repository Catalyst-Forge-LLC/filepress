FilePress turns Markdown in git into a static site. No CMS. No database. No server at runtime.

Start empty, or [import](/docs/import) a public site. [Genie](/docs/genie) can steer look in `filepress dev`. It never ships in production. `filepress build` writes `build/`.

Written **FilePress**. npm **`getfilepress`**. CLI **`filepress`**.

## In these docs

- [Getting started](/docs/getting-started) — install, scaffold, config, posts
- [Import](/docs/import) — crawl a public site into a content tree
- [Genie](/docs/genie) — local design cockpit
- [Theme](/docs/theme) — tokens, presets, `theme.css`
- [Deploy](/docs/deploy) — static `build/` on any host
- [Skill page](/docs/skill-page) — if the site ships an agent skill
